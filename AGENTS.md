# Regras do projeto F-Zone VR

## Publicação automática

- Após concluir qualquer alteração solicitada neste projeto, execute as validações relevantes, crie um commit e publique diretamente na branch `main` do repositório `lochesystem/f-zone-vr`.
- Não abra pull request, salvo quando o usuário pedir explicitamente.
- Só deixe de publicar quando o usuário pedir para não publicar, quando uma validação falhar ou quando autenticação/permissão impedir o push. Nesses casos, informe claramente o impedimento.
- Depois do push, confirme o resultado do workflow **Publicar no GitHub Pages** e informe o link da versão publicada.
